# itinera-macros

The procedural macros of [`itinera`](https://crates.io/crates/itinera), the Rust implementation of [Itinera](https://itinera-dev.org/), a workflow framework that keeps business rules separate from flow control.

Applications reach these macros through `itinera`: most behind its `macros` feature, which is on by default, and `async_trait` behind its `async` feature. Add `itinera` rather than this crate; [its documentation](https://docs.rs/itinera) and [the Itinera book for Rust](https://itinera-dev.org/book/rust/) explain how to use them.
