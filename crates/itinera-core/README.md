# itinera-core

The implementation behind [`itinera`](https://crates.io/crates/itinera), the Rust implementation of [Itinera](https://itinera-dev.org/), a workflow framework that keeps business rules separate from flow control.

Applications depend on `itinera`, which re-exports everything they use from this crate. Add `itinera` rather than this crate; [its documentation](https://docs.rs/itinera) and [the Itinera book for Rust](https://itinera-dev.org/book/rust/) explain how to use it.
